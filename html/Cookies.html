What Are Cookies?

  • Cookies store data as key-value pairs.
  • They are sent with every HTTP request to the server (unlike local storage).
  • Can have an expiration time.
  • Commonly used for authentication, session management, and tracking.

Differences Between Cookies and Local Storage

FeatureCookiesLocal Storage
Size~4KB per cookie~5-10MB
ExpirationCan expire after a set timeNever expires (until cleared)
Accessible by ServerYes, sent with every requestNo
StorageKey-Value pairsKey-Value pairs
SecurityCan be made secure (HttpOnly)Accessible via JavaScript

How to Use Cookies in JavaScript

1. Setting, Getting, and Deleting Cookies

Here’s how you can manipulate cookies in JavaScript.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Cookies Example</title>
</head>
<body>
    <h1>Cookies Example</h1>
    <p>Enter your name, and we'll save it in a cookie!</p>

    <!-- Input for user name -->
    <input type="text" id="nameInput" placeholder="Enter your name">
    <button id="setCookieBtn">Save Name</button>
    <button id="deleteCookieBtn">Delete Cookie</button>

    <p id="message"></p>

    <script>
        // Function to set a cookie
        function setCookie(name, value, days) {
            const date = new Date();
            date.setTime(date.getTime() + (days * 24 * 60 * 60 * 1000)); // Set expiration
            const expires = "expires=" + date.toUTCString();
            document.cookie = `${name}=${value};${expires};path=/`;
        }

        // Function to get a cookie by name
        function getCookie(name) {
            const cookies = document.cookie.split(';');
            for (let cookie of cookies) {
                cookie = cookie.trim();
                if (cookie.indexOf(name + "=") === 0) {
                    return cookie.substring(name.length + 1);
                }
            }
            return "";
        }

        // Function to delete a cookie
        function deleteCookie(name) {
            setCookie(name, "", -1); // Set expiration to the past
        }

        // DOM Elements
        const nameInput = document.getElementById("nameInput");
        const setCookieBtn = document.getElementById("setCookieBtn");
        const deleteCookieBtn = document.getElementById("deleteCookieBtn");
        const message = document.getElementById("message");

        // Save cookie
        setCookieBtn.addEventListener("click", () => {
            const userName = nameInput.value.trim();
            if (userName) {
                setCookie("userName", userName, 7); // Expires in 7 days
                displayMessage();
                nameInput.value = "";
            } else {
                alert("Please enter a name!");
            }
        });

        // Delete cookie
        deleteCookieBtn.addEventListener("click", () => {
            deleteCookie("userName");
            message.textContent = "Cookie deleted!";
        });

        // Display greeting message if cookie exists
        function displayMessage() {
            const userName = getCookie("userName");
            if (userName) {
                message.textContent = `Welcome back, ${userName}!`;
            } else {
                message.textContent = "No name saved yet!";
            }
        }

        // Show message on page load
        window.addEventListener("DOMContentLoaded", displayMessage);
    </script>
</body>
</html>

2. How It Works

  1. Set a Cookie:
    • The setCookie function sets a cookie with an expiration time.
    • Cookies have the format: key=value; expires=...; path=/.
  1. Get a Cookie:
    • The getCookie function splits the document.cookie string and retrieves the desired value.
  1. Delete a Cookie:
    • Cookies are deleted by setting their expiration date to a time in the past.
  1. Greeting Message:
    • When the page loads, it checks for the "userName" cookie and displays a personalized message if it exists.

3. Testing Cookies

  1. Save the code as an HTML file and open it in a browser.
  1. Enter a name and click Save Name.
    • The name will be saved in a cookie for 7 days.
  1. Refresh the page → The name will persist.
  1. Click Delete Cookie → The cookie will be cleared, and the message will reset.

4. Checking Cookies in the Browser

  • Open Developer Tools in your browser (F12 or Ctrl+Shift+I).
  • Go to the Application tab → Cookies.
  • You’ll see the cookies saved for your website, including their values and expiration.

Security Considerations

  1. HttpOnly Flag:
    • Use the HttpOnly flag on the server side to prevent JavaScript from accessing cookies (protects against XSS attacks).
  1. Secure Flag:
    • Use the Secure flag to ensure cookies are only sent over HTTPS.

Example (server-side cookies):

Set-Cookie: userName=John; HttpOnly; Secure; SameSite=Strict

When to Use Cookies vs. Local Storage

  • Use Cookies when you need to:
    • Send data to the server (e.g., authentication tokens).
    • Have a small amount of data that requires an expiration date.
  • Use Local Storage when you need to:
    • Store larger amounts of data (e.g., preferences, themes).
    • Keep data that doesn’t need to be sent to the server.
